# Notion 格式转换指南

## Markdown vs Notion API 对比

| Markdown | Notion API | 说明 |
|----------|------------|------|
| `# 标题` | `heading_1` block | 一级标题 |
| `## 标题` | `heading_2` block | 二级标题 |
| `### 标题` | `heading_3` block | 三级标题 |
| `- 列表项` | `bulleted_list_item` | 无序列表 |
| `1. 列表项` | `numbered_list_item` | 有序列表 |
| `> 引用` | `quote` block | 引用块 |
| `` `代码` `` | 行内代码（无） | **不支持**，用普通文本 |
| ``` 代码块 ``` | `code` block | 代码块 |
| `---` | `divider` | 分隔线 |
| `**粗体**` | rich_text bold | **支持** |
| `*斜体*` | rich_text italic | **支持** |
| `$公式$` | **不支持** | 必须转为文本 |
| `$$公式$$` | **不支持** | 必须转为代码块或文本 |
| `[链接](url)` | **不支持** | 用纯文本URL |
| `![图片](path)` | 需单独上传 | **不支持**在markdown中 |

## 关键限制

### 1. 字符限制
- 每个 rich_text 项最多 **2000 字符**
- 超长内容会被自动分割

### 2. 公式处理规则

**LaTeX 公式必须转换：**

| 原始公式 | 转换方式 | 示例 |
|----------|----------|------|
| 行内 `$x^2$` | Unicode 上标 | `x²` |
| 行内 `$\alpha$` | Unicode 符号 | `α` |
| 块级 `$$...$$` | 代码块或描述文本 | 见下方 |

**块级公式示例：**

原 LaTeX:
```latex
$$
\mathcal{L} = \sum_{i=1}^{N} \log p(x_i | \theta)
$$
```

转换为代码块:
```
Loss = Σ log p(xᵢ | θ)
```

或描述文本:
```
损失函数为对所有样本的对数概率求和
```

| `\theta` | θ | 希腊字母 |
| `\lambda` | λ | 希腊字母 |
| `\Sigma` | Σ | 求和符号 |
| `\sum` | Σ | 求和 |
| `\infty` | ∞ | 无穷 |
| `\partial` | ∂ | 偏导 |
| `\nabla` | ∇ | 梯度 |

| `\geq` | ≥ | 大于等于 |
| `\neq` | ≠ | 不等于 |

| `\times` | × | 乘号 |

| `\sqrt{x}` | √x | 根号 |

### 4. 标题层级规则

**必须使用正确的层级：**

```markdown
# 论文标题（一级，仅用于标题）

## 论文一：标题（二级，每篇论文）

### 研究背景（三级，章节）

具体内容使用普通段落...

### 方法论

具体内容...

### 实验结果

具体内容...

## 论文二：标题

...
```

**错误示例：**
```markdown
### 这里的标题不对

这里是内容 ### 标题不应该在行内
```

### 5. 列表格式

**正确格式（每行独立）：**
```markdown
- 第一项
- 第二项
- 第三项
```

**错误格式：**
```markdown
- 第一项，这是很长的一段内容
  这里换行了但不是列表项
```

### 6. 表格处理

**Markdown 表格不会被自动转换！**

必须改为列表或描述文本：

```markdown
原表格：

| 方法 | 准确率 | F1 |
|------|--------|-----|
| Ours | 95.2% | 0.93 |
| Base | 90.1% | 0.88 |

转换为：

**实验结果：**
- Ours: 准确率 95.2%, F1 0.93
- Base: 准确率 90.1%, F1 0.88
```

### 7. 图片引用

**不支持 Markdown 图片语法！**

使用文本描述：
```markdown
（参见实验结果图：images/paper_page1_fig1.png）
```

## 输出模板

### ACC 报告模板

```markdown
# 论文日报 - {日期}

## 论文一：{英文标题}

**arXiv ID**: {id}

### 研究问题

{问题描述}

### 核心方法

方法的核心思想是...

主要公式：

Loss = α × L₁ + β × L₂

其中：
- L₁ 表示重建损失
- L₂ 表示正则化项

### 实验结果

主要发现：
- 发现一
- 发现二

### 评价

**优点**：
- 优点一
- 优点二

**不足**：
- 不足一
- 不足二

**评分**: Accept / Minor Revision / Major Revision / Reject

---

## 论文二：{英文标题}

...
```

```markdown
# 实验报告 - {日期}

## 论文一：{英文标题}

### 实验概述

- 实验类型：基准测试
- 数据集数量：3 个
- 基线方法数量：5 种

### 数据集

**数据集一：CIFAR-10**
- 来源：图像分类基准
- 规模：60,000 张图片
- 划分：50,000 训练 / 10,000 测试

### 主要结果

- Ours: 准确率 95.2%, F1 0.93
- Baseline-1: 准确率 90.1%, F1 0.88
- Baseline-2: 准确率 88.5%, F1 0.85

- 去除组件A：性能下降 3.2%
- 去除组件B：性能下降 1.5%

---

## 论文二：{英文标题}

...
```

## 禁止事项

1. **禁止**使用行内 `###` 等标题符号
2. **禁止**输出 LaTeX 公式（必须转换）
3. **禁止**使用 Markdown 表格（转为列表）
4. **禁止**使用 `![图片]()` 语法（用文本描述）
5. **禁止**使用 `[链接]()` 语法（用纯文本URL）
6. **禁止**使用行内代码 `` `code` ``（Notion不支持）
